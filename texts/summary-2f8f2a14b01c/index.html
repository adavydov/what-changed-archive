HackerTube: свой YouTube из чужих рекомендаций

Андрей Карпати, исследователь AI и сооснователь OpenAI, описывает небольшой личный проект HackerTube. Раздражение рекомендациями YouTube превратилось в альтернативный интерфейс, который использует уже накопленный людьми корпус рекомендаций Hacker News.

Основные мысли

  • Корпус рекомендаций Hacker News стал основой 6454 видео по 150 темам в отдельном интерфейсе YouTube.
  • Кадры из середины видео заменяют обложки, состояние пользователя хранится локально, данные можно экспортировать своему агенту.
  • Карпати общался с агентом вместо чтения кода; ключ Google Cloud, VPS и домен создал сам, затем поручил доставку и защиту.

Вечером Карпати открыл YouTube и остался недоволен преувеличенными обложками и повторяющимися рекомендациями. На следующее утро он поручил Opus 5.5 собрать собственный вариант сервиса из видео, которые люди рекомендовали на Hacker News. Агент загрузил открытый корпус комментариев, отфильтровал его и запустил Sonnet в Workflow Claude Code. После удаления спама осталось около 40 тысяч комментариев с рекомендациями:6454 видео за 2007–2026 годы, распределённые по 150 темам.

Продукт меняет слой отбора и интерфейса поверх уже существующих видео. Вместо загруженной автором обложки HackerTube показывает кадр из середины ролика. Персональные рекомендации работают без аккаунта, сохраняя состояние локально в браузере. Есть клавиатурные сокращения и экспорт данных сайта, который можно отдать своему агенту и сделать следующую версию под себя. Карпати называет общую длительность работы примерно в два часа.

В дополнении от 1 ноября он раскрывает процесс доставки. Работал через приложение Claude Code на Mac, выбрав Opus 5.5 с усилием Medium, и общался с агентом вместо чтения кода и команд терминала. Три действия сделал сам: получил ключ в Google Cloud для метаданных YouTube, запустил VPS и купил домен. После этого передал агенту IP и поручил обновление, развёртывание, защиту и оптимизацию. Таким образом, за коротким описанием самостоятельной разработки стоит уже созданный человеком доступ к внешним сервисам и инфраструктуре.
