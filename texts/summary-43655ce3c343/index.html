System One в приложении: решения между строками обычного кода

Ричард Макманус пересказывает демонстрации AI Engineer Code Summit, посвящённые быстрым моделям выбора. После выступления создателя Jev он разбирает конкретные способы встроить такие вызовы в продукт.

Основные мысли

  • Glean использует Jev, когда список классов меняется и не хочется снова дообучать отдельный классификатор.
  • UiPath построил турнир ранжирования фрагментов: тысячи малых решений укладываются меньше чем в секунду.
  • Прототип Workday начинает оформлять действие, пока пользователь ещё печатает запрос.

Модель как элемент кода

Диогу Алмейда предлагает шире встраивать модели, возвращающие выбор, оценку или вероятность, в обычный код. Его претензия к большому генеративному ответу — трудно автоматизировать работу, когда система иногда выдаёт сильный результат, а иногда проваливается и не показывает, какой из случаев произошёл. Метафора про Эйнштейна в 95% случаев и мистера Бина в 5% передаёт именно эту проблему распознавания ошибки.

Гибкость вместо повторного обучения

Чинмай Гойал из Glean объясняет, что компания использует Jev рядом с LLM и другими классификаторами. Его преимущество для части задач — гибкость без примеров: когда меняется набор допустимых категорий, не нужно заново дообучать модель. Для пользователя приложения различия внутри модельного стека скрыты за работающим сценарием.

На показанном слайде Гойал даёт практическое правило выбора. Если результат можно заранее перечислить, стоит проверить decision model. Если классы стабильны и объём велик, рядом нужно сравнить дообученный классификатор. Для свободного текста остаётся генеративная модель; в гибриде Jev выбирает инструмент, а LLM пишет его аргументы.

Тысячи простых выборов складываются в алгоритм

Команда UiPath показывает ранжирование фрагментов документа турнирным способом. Jev выбирает лучшие элементы небольших групп, победители переходят в следующий раунд, затем процедура повторяется. По словам выступающих, тысячи вызовов в этом прототипе заняли меньше секунды. Чиби Викрам описывает Jev как строительный блок: новые стратегии вокруг простого решения могут дать более сложное поведение системы.

Слайд UiPath раскладывает работу с документами на семь типов короткого вопроса: выбрать релевантное, отнести сообщение к делу, определить вид документа, найти начало раздела, извлечь поле, связать значение со словами-источниками и проверить требование. Общая форма — один сфокусированный вопрос с ответом, который программа может сразу использовать.

Действовать до конца запроса

Скотт Робертс из Workday демонстрирует прототип, который начинает заполнять карточку отпуска во время набора текста. Быстрое решение меняет момент действия интерфейса: программа предсказывает, что человек хочет сделать, пока он ещё формулирует запрос.

Макманус завершает статью наблюдением о новых формах программ. Участник конференции рассказывает ему о личном сайте ранжирования новостей fantasy football на Jev. Алмейда сравнивает этот период с ранним интернетом, когда люди исследовали новые возможности ещё до появления устойчивого представления об их ценности.
