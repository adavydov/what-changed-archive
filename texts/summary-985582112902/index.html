Ахмад Осман: локальному AI нужен полный рабочий контур

Три основных вывода

  1. Друг купил RTX 5090, запустил Qwen 3.5 через Claude Code и попросил изменить подсветку видеокарты. Локальный агент не справился, тогда как hosted Claude Code справился; причина оказалась не в отсутствии «интеллекта» модели, а в том, что локальному контуру не дали веб-поиск по обновившейся документации. После подключения поиска та же система выполнила задачу. Поэтому Osmantic собирает вместе чат, загрузку документов, агента, tool harness и search.
  2. Корпоративные посетители спрашивали уже не «сколько видеокарт дома», а о маршрутизации моделей, сборе трасс, песочнице для агента и задержке. Осман предлагает гибрид: простое и чувствительное обрабатывать на локальной или выделенной colocated машине, сложное при необходимости отправлять в облако. Важна возможность сохранить собственные данные, политику доступа и стабильную версию модели, если поставщик API меняет качество, цену или правила.
  3. Следующий шаг, по Осману, — собирать сообщения и оценки сотрудников как данные для специализированной модели компании: это может повысить точность и снизить стоимость узкой работы. Он предполагает, что создатели открытых моделей будут зарабатывать на лицензиях для дообучения и коммерческого развёртывания, пока сам базовый слой остаётся доступным.

Оригинал

Кто говорит: Ахмад Осман — основатель открытой платформы Osmantic для запуска локального AI; отвечает на вопросы Latent Space после двух воркшопов AI Engineer World’s Fair.

Главная мысль: Локальный AI становится практичным не в тот момент, когда модель помещается на домашний GPU, а когда вокруг неё появляется весь рабочий контур: поиск, инструменты, агентная оболочка, данные, трассировка и изоляция. Уменьшение лага открытых моделей делает этот контур альтернативой облачной зависимости для частных и корпоративных задач.

  • На воркшопе Осман дал посетителям сравнить DGX Spark, AMD Strix Halo и другие локальные машины с облачной моделью по скорости, качеству и задержке. По его оценке, открытые модели ещё отстают от закрытого фронтира примерно на четыре–восемь месяцев, но небольшой 4-bit Qwen уже запускается на MacBook, а модели на телефонах превосходят облачные системы нескольких лет давности.
  • Друг купил RTX 5090, запустил Qwen 3.5 через Claude Code и попросил изменить подсветку видеокарты. Локальный агент не справился, тогда как hosted Claude Code справился; причина оказалась не в отсутствии «интеллекта» модели, а в том, что локальному контуру не дали веб-поиск по обновившейся документации.
