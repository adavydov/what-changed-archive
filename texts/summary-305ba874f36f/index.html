Саймон Уиллисон: полчаса голосовой разработки и ещё полчаса проверки за клавиатурой

Уиллисон добавил в Django-блог общий архив рассылок, разговаривая с Codex во время приготовления ужина. Он подробно показывает, что агент сделал голосом, какие решения пришлось поправить при ревью и почему предпочитает этот режим для совмещения занятий.

Основные мысли

  • Примерно за полчаса голосового диалога агент создал модель данных, импорты, архивные страницы и поиск для заранее понятной автору Django-функции.
  • Перед публикацией понадобилось ещё около получаса текстовых запросов: Уиллисон заменил импорт через Git на API, настроил доступ и поправил отображение.
  • Для автора главная польза — сочетание голоса с просмотром результата и возможностью печатать; детали, сообщения об ошибках и точечные правки он по-прежнему быстрее передаёт клавиатурой.

Разговор с работающей локальной версией

Уиллисон хотел собрать в одном месте бесплатную еженедельную рассылку Substack и ежемесячные выпуски для спонсоров. Он начал с локального checkout своего блога: попросил запустить сервер и открыть сайт в браузере, затем включил голосовой разговор во вкладке Codex настольного приложения. Это отдельный режим диалога, а не кнопка диктовки. Ноутбук стоял на кухне, и автор время от времени смотрел на превью.

Задача была ему хорошо понятна и достаточно проста для Django: новая модель, миграция, представления, шаблоны и функции импорта. Он использовал GPT-6 Astra High. Речь получалась с паузами и исправлениями: автор менял решение о том, где показывать рассылки, и уточнял условия поиска. Например, письма не должны попадать на главную и страницы тегов, но должны появляться в календарных архивах. Еженедельные выпуски дублируют материалы блога, а ежемесячные содержат уникальный текст и должны индексироваться после открытия доступа через месяц.

Что появилось за ужином и что осталось для ревью

За примерно полчаса диалога агент создал модель и миграцию, настройки Django Admin и четыре импорта: свежие выпуски Substack через RSS, старый архив через недокументированный API, опубликованные месячные выпуски из GitHub и последний закрытый выпуск из частного репозитория. Для пагинации Substack агент дополнил знание адреса API поиском инструкции. Появились общий и годовой архивы, включение в дневные и месячные страницы, разные ссылки для двух типов выпусков и интеграция с поиском.

Готовность к публикации требовала другой работы. Агент предложил выгрузить локальные данные для production, а Уиллисон хотел обычный повторяемый импорт и знал, что частный репозиторий потребует настройки API-ключа. Закончив готовить, он попросил создать ветку и pull request и прочитал изменения в GitHub. Один импорт вызывал Git отдельным процессом; автор счёл API более подходящим и через текстовые запросы заменил механизм. Заодно поправил внешний вид страниц. Ещё примерно полчаса ушло на этот этап до слияния PR и развёртывания.

В опубликованном результате оба вида рассылок идут вместе в обратном хронологическом порядке, ниже доступны архивы по годам. Еженедельные выпуски ведут в Substack, публичные ежемесячные имеют свои страницы. Дизайн создавал агент и менял по голосовым замечаниям автора, смотревшего на локальную версию через кухню.

Где голос оказывается удобен

Уиллисон раньше использовал голосовой ChatGPT на прогулках для поиска, обсуждения идей и иногда небольших программных экспериментов. Здесь сочетание с визуальным превью и клавиатурой сделало работу сильнее: можно видеть результат и при необходимости вставить то, что трудно произнести. Но основным ежедневным способом он этот режим не считает. Примеры, ошибки и выделение конкретного участка кода проще передавать непосредственно. В общем рабочем пространстве постоянный разговор с компьютером ему тоже был бы неудобен. Для него главное — возможность создавать функцию параллельно с готовкой, когда раньше звучал подкаст или TikTok.
