Code review получил память организации

История 05

29 июля GitHub сделала agent skills и MCP для Copilot code review общедоступными в планах Pro, Pro+, Business и Enterprise. Автоматический reviewer теперь может опираться не только на diff и репозиторий, но и на явно подключённые правила и рабочие системы команды.

Файл SKILL.md в каталоге .github/skills добавляет стандарты и инструкции конкретного репозитория или организации. MCP-соединения подтягивают контекст из issue trackers, документации и service catalogs. Настройки, уже созданные для cloud agent, применяются и к code review.

GitHub ограничивает MCP tool calls в review режимом read-only. Комментарий также показывает attribution, если был создан с помощью skill или MCP-контекста. Это превращает происхождение замечания из скрытой детали inference в видимую часть проверки.

Релиз подтверждает доступность механизма, но не его качество. GitHub не публикует precision, recall, долю принятых замечаний или влияние на defects. Плохое внутреннее правило теперь масштабируется так же легко, как хорошее.

Поэтому память reviewer должна быть версионированным продуктом: владелец правила, область действия, источник стандарта, тестовые нарушения и дата пересмотра. Read-only ограничивает действие инструмента, attribution объясняет контекст, но ни одно из них не доказывает правильность совета.
