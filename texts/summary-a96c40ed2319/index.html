Claude Mods: программируемый интерфейс человеческого внимания

Три основных вывода

  1. Модификация работает внутри цикла агента. TypeScript- или JavaScript-функции реагируют на запрос, вызов инструмента или отрисовку, наблюдают событие, меняют его представление и могут заменить стандартную обработку. Это middleware для исполнения и интерфейса CLI/Desktop. Встроенный навык позволяет заказать новую модификацию обычным языком. Автор описывает разворот оболочки: прежний интерфейс между агентом и машиной становится программируемым интерфейсом между агентом и человеком. [Claude Mods; The harness reversal]
  2. Три продукта распределяют право проектировать внимание по-разному. В описанном автором ChatGPT Intelligent UI модель выбирает интерфейс ответа внутри готовой библиотеки компонентов. Cursor PR Routing & Approval распределяет ревью по владельцам кода и истории, учитывает риск, проверки и политику команды и может автоматически одобрять низкорисковые изменения. Такой механизм не заменяет полноценное ревью кода. Существенная деталь Cursor: если PR меняет политику одобрения, для него используется версия из базовой ветки — нельзя ослабить собственную проверку тем же изменением. Claude Mods позволяют пользователю с агентом написать саму логику взаимодействия. [Attention Interfaces elsewhere; Differences]
  3. Частота предупреждений способна уничтожить их пользу. У Макатира порог Supervisor сработал в 99 из 111 сессийных ходов: полезные замечания смешались с шумом, и он стал их просматривать невнимательно. Каждая проверка заново читает ответвлённую беседу; README оценивает расход примерно в 5–6 тыс. входных эквивалентных токенов для сессии на 50 тыс. токенов при работающем кэше. Модификация также исполняется с правами пользователя, видит запросы и может менять файлы; автор отдельно отмечает отсутствие песочницы и работу встроенных модификаций даже в safe mode. [What’s wrong with Mods]

Оригинал

Кто говорит: Дэн Макатир, автор Latent Space и создатель открытого набора ModSmith; собственный опыт настройки Claude Code.

Главная мысль: Макатир рассматривает оболочку агента как будущую платформу управления человеческим вниманием. Когда модель забирает больше технической работы, ценность оставшегося интерфейса — вовремя показать человеку важное решение и дать удобный способ действовать. Claude Mods позволяют спроектировать этот слой вместе с самим агентом.

  • Anthropic сама использует эту конструкцию для частей продукта. Среди шести встроенных модификаций — загрузка AGENTS.md, показ diff, создание модификаций, защита настроек организации и телеметрия. You Should Know запускает бокового наблюдателя за основным агентом. Когда тот успешно упростил интерфейс приложения, наблюдатель заметил другое: редактируемый файл и ещё около 45 файлов уже содержали незакоммиченные изменения. Позднейшая отмена демонстрационных правок могла уничтожить прежнюю работу; предупреждение предложило сначала сохранить её. [Mods in practice; You Should Know]
  • Собственный Next Steps Supervisor превращает проверку в действие. Он включается после изменения файлов, команд или не менее восьми вызовов инструментов, показывает замечания и предлагает следующий шаг кнопкой, отправляющей команду Claude. Пользователь определяет, что считается важным, когда просить второе мнение и как реагировать. Это пример самостоятельного проектирования способа контроля, а не только выбора внешнего вида ответа. Макатир представляет фоновый процесс, который изучает стенограммы, находит повторные исправления и ручные проверки, предлагает модификацию и дорабатывает её по обратной связи. Его практический критерий уже сейчас: показала ли надстройка пропущенное, упростила ли решение, помогла ли действовать без лишнего отвлечения. Даже статус Solved однажды соседствовал у его Supervisor с двумя пробелами и тремя упрощениями. [Where this goes]
