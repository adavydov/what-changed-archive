Агенты меняют цель модернизации страхового SaaS

Три основных вывода

  1. Бюджет переносится с экранов на действия. В текущем проекте важнее API parity и единая модель данных, чем повтор старого интерфейса. Страховой специалист будет получать контекст и принимать решения; агент заполнит поля.
  2. Кастомизация создаёт налог на AI. Изменённые таблицы нарушают общую семантику claims, policy и finance. Регуляторный учёт сохраняют в устойчивом ядре, новые продукты и порталы подключают через управляемые API.
  3. Агенту требуется управление как сотруднику. Человек проектирует работу, ассистент координирует внутренних и сторонних агентов, агенты исполняют. Каждому нужны контекст, границы полномочий, отзыв доступа, история решений, обратная связь и вывод из эксплуатации. Ранние результаты специализированной оболочки Guidewire показывают на 40–50% большую эффективность по токенам и пропускной способности. Журнал и происхождение решения должны позволять объяснить его даже через десять лет.

Оригинал

Кто говорит: Джон Маллен — президент Guidewire; Кэти Реа — вице-президент Bessemer Venture Partners; Лэнс Сенойюит — старший советник SAP по финансовой отрасли. Беседу ведёт партнёр McKinsey Санджай Канияр.

Главная мысль: Участники предлагают продолжать модернизацию ядра, направляя инвестиции в данные, API и управляемые агентные процессы.

  • Открытое ядро становится основанием агентности. Чистые данные и API позволяют агенту проходить весь страховой процесс. AI одновременно ускоряет миграцию: сопоставляет данные, создаёт тесты и конфигурации.
  • Бюджет переносится с экранов на действия. В текущем проекте важнее API parity и единая модель данных, чем повтор старого интерфейса. Страховой специалист будет получать контекст и принимать решения; агент заполнит поля.
  • Кастомизация создаёт налог на AI. Изменённые таблицы нарушают общую семантику claims, policy и finance. Регуляторный учёт сохраняют в устойчивом ядре, новые продукты и порталы подключают через управляемые API.
  • Рабочая стратегия — build with. Покупают ядро, строят собственную дифференциацию; MCP/API сохраняют заменяемость агентов. Vibe coding не устраняет обслуживание, оценку качества и аудит. Сенойюит приводит портал, созданный тремя-четырьмя разработчиками: уход одного оставляет пробел в документации и тестировании. Владение продуктом требует учитывать весь срок его жизни.
  • Агенту требуется управление как сотруднику. Человек проектирует работу, ассистент координирует внутренних и сторонних агентов, агенты исполняют. Каждому нужны контекст, границы полномочий, отзыв доступа, история решений, обратная связь и вывод из эксплуатации. Ранние результаты специализированной оболочки Guidewire показывают на 40–50% большую эффективность по токенам и пропускной способности. Журнал и происхождение решения должны позволять объяснить его даже через десять лет.
  • Экономика меняет единицу измерения. Лицензии уступают вычислениям, токенам, оркестрации и контролю. Эффект считают по сроку обработки claim и исключениям относительно полной стоимости; удешевление миграции само по себе не определяет операционный TCO. Сенойюит вспоминает команду, потратившую годовой AI-бюджет за пару месяцев; отдельно предлагает заранее заложить управление AI, чтобы после запуска CFO не столкнулся с неожиданной потребностью нанять ещё четырёх человек.
