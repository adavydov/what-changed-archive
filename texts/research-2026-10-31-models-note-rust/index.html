Дешёвый код сделал полный порт API разумным, а проверку — главным проектом

Anthropic столкнулась с CPU-пределом Python-монолита и переписала весь Messages API на Rust, хотя в начале проекта в комнате не было ни одного Rust-разработчика. Claude писал реализацию; люди проектировали систему и проверку. Старый и новый API получали shadow traffic, а команда сравнивала их ответы. Гости сообщают о снижении расхода CPU примерно на 40–50% и времени до первого токена на 10–20%.

Существенна конструкция проекта. Команда сопротивлялась желанию добавить заодно новые функции: это был чистый порт. Пока остальная организация развивала Python-API, статические проверки обнаруживали изменения, которые забыли перенести в Rust. Перестройку поведения и хранение состояния разговора оставили следующему этапу. Экономия на написании кода позволила взяться за большой переход, а проверяемая эквивалентность дала способ его контролировать.
