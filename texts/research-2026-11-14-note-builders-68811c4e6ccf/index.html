ArtCraft: знакомые приложения как основа для собственной версии софта

На AI Engineer Code Summit глава ArtCraft Брэндон Томас рассказывает, как команда создаёт открытые версии творческих приложений. Ричарда Макмануса интересует и техническая работа агентов, и возникшее вокруг проекта сообщество.

Томас вспоминает ранний Web с открытыми протоколами и средами, в которых можно было самостоятельно строить инструменты. Web 2.0 расширил аудиторию, но крупные платформы закрыли API и контроль над распространением. ArtCraft отвечает открытыми приложениями и инфраструктурой: среди проектов есть PhotoCraft, WordCraft, другие версии привычных инструментов и самостоятельные разработки сообщества.

Для PhotoCraft команда составила подробное описание инструментов Photoshop, структур данных и импорта файлов, затем поручила модели собрать приложение. Всё делали доступным через MCP и CLI. По словам Томаса, уже через сутки появилась хорошая приблизительная версия.

Компания пока не заявляет полного паритета. На сцене Томас говорит о прохождении примерно 60%; Макманус отдельно приводит цифры GitHub — около 76% широты функций и 46% профессиональной готовности. Сначала ArtCraft хочет сохранить привычные движения пользователей Adobe. После этого планирует интерфейсы с большей ролью агентов и возможность художнику дорабатывать собственный процесс.

Томас сообщает примерно о 4000 разработчиков в сообществе, 17 официальных приложениях и около 300 общественных разработок. Загрузки приложений, по его словам, достигли примерно 1,7 млн в день и продолжают расти. Он связывает отклик с желанием людей снова владеть своими инструментами.

Для производительности команда использует Rust. Томас утверждает, что PhotoCraft открывается в десять раз быстрее Photoshop, и считает нативную среду важной для творческого софта. При этом он полагает, что начать можно без собственного глубокого знания Rust: агенты помогают писать код.

Граница делегирования проходит по типу изменений. Backend, миграции схем и проектирование API он советует оставлять людям. Desktop, игры и задачи с более неизменяемым результатом команда увереннее отдаёт агентам. Выросшие объёмы работы уже создают трудности с правами, GitHub, CI и памятью; команда строит свои CI-мощности и использует colocated-серверы.

Томас собирается открыть AutoCraft — автономную фабрику разработки. Макманус завершает материал собственным интересом к человеческому сообществу вокруг этого процесса: агенты делают основную кодовую работу, а люди развивают общую среду и свои инструменты.
