Datasette Apps: отдельные права на запросы для каждого приложения

В обновлении Datasette Apps 0.3a0 Саймон Уиллисон уточняет, как созданные агентом HTML-приложения получают доступ к данным. Приложение связывается с разрешёнными сохранёнными запросами, а операции записи требуют согласия пользователя.

Основные мысли

  • Агент может добавлять и удалять сохранённые запросы, которые разрешено вызывать конкретному приложению.
  • Перед выдачей доступа к запросу записи система запрашивает одобрение пользователя.
  • При создании приложения проверяются существование запрошенных запросов и право пользователя их видеть.

Права задаются на уровне приложения

Новые инструменты app_add_stored_queries() и app_remove_stored_queries() управляют списком сохранённых запросов, доступных приложению. Для запроса, который изменяет данные, сначала требуется одобрение пользователя. app_create() также проверяет, что каждый запрошенный запрос существует и виден пользователю, и получает согласие на запись до создания приложения.

Как приложение попадает в разговор

Приложение можно упомянуть в чате Datasette Agent через #. Автодополнение предлагает только те приложения, которые пользователь имеет право просматривать. Кнопка View app и ссылка на такое упоминание открывают приложение на всю область панели агента. Так обновление соединяет навигацию в чате с конкретным набором разрешений на работу с данными.
