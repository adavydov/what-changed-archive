OpenAI: самопроверка computer use и быстрые решения через API

Ари Вайнштейн, отвечающий в OpenAI за computer use, и Никундж Ханда из продуктовой команды API обсуждают с Latent Space устройство новых агентных инструментов. Разговор соединяет работу в браузере, короткие структурированные решения и инфраструктуру длительных задач.

Основные мысли

  • Computer-use агент выбирает между картинкой, структурой страницы и кодом, а затем проверяет и исправляет свои действия.
  • Decisions API предназначен для быстрых ограниченных ответов, например классификации обращения или выбора действия.
  • Асинхронные инструменты, двустороннее соединение и кэш помогают продолжать длинную работу без постоянного перезапуска.

Агент, который видит и проверяет

Вайнштейн связывает прогресс computer use с самопроверкой и доступом к устройству интерфейса. Агент выбирает скриншот, accessibility-дерево, DOM или Playwright, пишет JavaScript для серии шагов и разбирает сбой. App Shot добавляет к картинке адреса ссылок и полный текст обрезанных элементов календаря из разметки для экранных читалок. Иногда ожидание самого сайта уже занимает больше времени, чем вычисление модели.

В Dot агент получает отдельную облачную Linux-машину с браузером. Он может открыть созданное приложение, испытать его и исправить видимые ошибки. Поставка computer use включает обученный для этой работы harness: через Agents API разработчикам предоставляется тот же стек, который использовался при обучении и работает в Codex и ChatGPT. Вайнштейн ожидает от этого улучшения скорости, цены и точности. Платёж требует согласия человека, а доступ к сайтам ограничивается задачей.

Быстро выбрать одно действие

Decisions API работает на весах Luna. После появления Jev команда за неделю собрала ограниченный предпросмотр с низкой задержкой до первого структурированного решения и возможностью задавать вопросы параллельно. Среди первых применений — классификация обращений и выбор действия для голосового интерфейса. Калибровка вероятностей и длинное рассуждение решают другие задачи.

Как поддерживать длительную работу

Асинхронные инструменты и mid-turn steering позволяют продолжить рассуждение без перезапуска, а WebSocket сохраняет двусторонний канал. По оценке Вайнштейна, Sol обходится примерно в пятую часть стоимости Astra в целом и в седьмую для computer use.

Кэш гарантируется в пределах 30 минут; режим на 12 часов ещё тестируется. Когда контекст заполняется, Agents API сжимает его внутри harness. Responses API даёт выбрать автоматический порог сжатия или вызвать его явно.
