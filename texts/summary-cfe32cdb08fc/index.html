Latent Space: computer use как проверяющий агент и Decisions API для быстрых решений

Три основных вывода

  1. Агент теперь исправляет собственные действия. Вместо одного скриншота он выбирает изображение, accessibility-дерево, DOM или Playwright, пишет JavaScript для серии шагов и разбирает сбой. App Shot добавляет к картинке адреса ссылок и полный текст обрезанных элементов календаря из разметки для экранных читалок. Порой ожидание стороннего сайта уже дольше вычисления модели.
  2. Decisions API работает на весах Luna. После Jev команда за неделю собрала ограниченный предпросмотр: структурированный ответ, низкая задержка до первого решения и параллельные вопросы. Первые применения — классификация обращений и выбор действия голосовым интерфейсом; калибровка и длинное рассуждение остаются отдельными задачами.
  3. Длинная работа меняет протокол вызова. Асинхронный инструмент и mid-turn steering дают продолжить рассуждение без перезапуска; WebSocket держит двусторонний канал. По Вайнштейну, Sol стоит около пятой части Astra в целом и седьмой для computer use. Гарантирован кэш в пределах 30 минут, 12-часовой режим тестируется; при заполнении контекста Agents API сжимает его внутри harness, а Responses API предлагает автоматический порог или явный вызов.

Кто говорит: Ари Вайнштейн руководит продуктом и разработкой агентов computer use в OpenAI; Никундж Ханда руководит продуктовой командой API OpenAI. С ними беседуют ведущие Latent Space.
