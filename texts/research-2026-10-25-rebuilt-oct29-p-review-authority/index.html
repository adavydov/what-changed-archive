Агент не должен менять правило, по которому одобряется его же изменение

В статье о Claude Mods есть легко пропускаемое правило Cursor PR Routing & Approval. Если pull request меняет политику одобрения, система проверяет его по версии этой политики из базовой ветки. Проверяемое изменение не может одновременно сделать собственную проверку мягче.

Это отдельная граница полномочий. Проверка кода может быть умной и всё равно бессмысленной, если критерий успеха разрешено переписать внутри того же действия. Для рабочих агентов возникает аналогичный вопрос о версиях рубрики, разрешений и правил завершения: какие из них являются входом в решение, а какие агент только предлагает изменить? Перенос не требует запретить изменение процесса навсегда. Он требует проверять изменение правил по уже принятому основанию.

В самом описании Cursor такой маршрут не заменяет полноценного ревью. Здесь ценна конкретная конструкция с версией авторитетного правила; из неё не следует, что вся остальная проверка уже решена.
