Ламберт: запрет открытых моделей может увеличить разрыв между атакой и защитой

Три основных вывода

  1. Техническая оценка атаки не объясняет последствия запрета. Ламберт признаёт ценность исследования Anthropic о GLM-5.3, но отдельно спрашивает, что произойдёт с защитой и почему китайские лаборатории выпускают веса. Каждое политическое решение меняет форму риска.
  2. Закрытый API тоже распространяет опасные возможности. В известных Ламберту публичных данных большинство AI-атак связано с закрытыми моделями. Их сила и доступность могут перевешивать защитные ограничения. По его логике, запрет открытых весов из-за кибервозможностей требует и запрета публичных API с такими возможностями.
  3. Защитникам нужны локальные модели: изолированная государственная система не может отправлять данные внешнему API. Если открытые веса запретят, пока атакующие возможности закрытых моделей растут быстрее ограничений, сопоставимая защита на частной инфраструктуре будет отставать. Ламберт предполагает, что распространение открытых моделей для обороны уменьшит ближайший ущерб.

Оригинал

Кто говорит: Натан Ламберт, исследователь обучения языковых моделей и автор Interconnects.

Главная мысль: Ламберт считает, что запрет американских открытых весов не остановит атакующие возможности, но может лишить защитников моделей для собственной инфраструктуры. Киберриск нужно оценивать по последствиям для всей экосистемы.

  • Техническая оценка атаки не объясняет последствия запрета. Ламберт признаёт ценность исследования Anthropic о GLM-5.3, но отдельно спрашивает, что произойдёт с защитой и почему китайские лаборатории выпускают веса. Каждое политическое решение меняет форму риска.
  • Закрытый API тоже распространяет опасные возможности. В известных Ламберту публичных данных большинство AI-атак связано с закрытыми моделями. Их сила и доступность могут перевешивать защитные ограничения. По его логике, запрет открытых весов из-за кибервозможностей требует и запрета публичных API с такими возможностями.
  • Защитникам нужны локальные модели: изолированная государственная система не может отправлять данные внешнему API. Если открытые веса запретят, пока атакующие возможности закрытых моделей растут быстрее ограничений, сопоставимая защита на частной инфраструктуре будет отставать. Ламберт предполагает, что распространение открытых моделей для обороны уменьшит ближайший ущерб.
  • У Китая другая система стимулов и контроля. Крупные релизы регистрируют у государства; первоначальные проверки связаны с контролем информации, а охват кибер- и биорисков остаётся неясным. Ламберт предполагает высокую личную цену внутренних инцидентов для руководителей лабораторий. Одновременно подробная проверка frontier-модели может требовать десятков миллионов долларов вычислений, конкурируя с обучением. Поэтому содержательный вопрос — минимальный объём и прозрачность проверок перед релизом.
  • Прогнозы должны допускать проверку наблюдениями. Через месяц после выпуска GLM-5.3 Ламберт не видит в публичных данных обещанного качественного скачка разрушительных атак. От возможной утечки Claude Mythos он ожидает ускорения существующей угрозы и роста инцидентов.
