Уиллисон: AI-пул-реквест как сообщение об ошибке с примером

В заметке о выпуске LLM 0.37 Саймон Уиллисон описывает обновления своей CLI-утилиты и опыт работы с AI-пул-реквестами. За два месяца проект накопил новые способы подключения моделей, поддержку мультимодальных embeddings и исправления от двенадцати авторов.

Основные мысли

  • Уиллисон использует Opus 5.5 и GPT-6 Astra для первичного разбора AI-пул-реквестов и поиска полезных исправлений.
  • Предложенный патч для него служит сообщением об ошибке с примером: он может принять его или написать своё решение.
  • LLM 0.37 упрощает подключение совместимых API и учитывает типы бинарного содержимого в мультимодальных embeddings.

Как обрабатывать входящие изменения

За этот выпуск исправления внесли двенадцать авторов, почти все с помощью AI. Уиллисон пишет, что нагрузка на него оказалась существенно ниже ожидаемой. Он рассматривает такой пул-реквест как сообщение об ошибке с приложенным примером. Opus 5.5 или GPT-6 Astra помогают с разбором и отбором полезных исправлений; окончательное решение остаётся у сопровождающего проекта. Иногда он принимает предложенный патч, иногда реализует исправление сам.

Что изменилось в инструменте

В LLM добавлены GPT-6.1 Sol и Terra и команда llm openai endpoint add для подключения моделей через совместимые с OpenAI API. Стандартной моделью для пользователей, которые не выбрали собственную, стала GPT-6 Luna; Уиллисон отмечает вдвое меньшую цену относительно прежней GPT-5.6 Luna.

Поддержка embeddings теперь допускает разный content-type у бинарных данных. Это нужно мультимодальным моделям вроде Gemini Embedding 2, которые умеют работать с текстом, аудио, изображениями и видео.
