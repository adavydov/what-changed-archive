DevRel начинает поставлять знания прямо агенту, который пишет интеграцию

У команды Claude Platform есть API skill, и владеет им DevRel. Гости противопоставляют нынешний путь прежнему огромному cookbook по computer use: разработчик всё чаще загружает skill в coding agent и просит построить нужную интеграцию либо указывает эталонную архитектуру. Примеры остаются полезны, но уже прежде всего показывают возможную задачу и устройство решения.

В прежнем выпуске Modal рассказывала, как исправляет устаревшие примеры, которые агенты продолжают воспроизводить. Здесь появляется следующий шаг: лучшие практики оформляют в артефакт, непосредственно участвующий в создании клиентского кода. Это точный ранний пример изменения DevRel, который связывает содержание документации с тем, как агент реально подключает продукт.
